# Google Clone

Este proyecto es un clon de la página principal de Google creado con tecnologías web básicas.

## 🚀 Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript Vanilla

## ✨ Funcionalidades

- Barra de búsqueda.
- Redirección a Google al realizar una búsqueda.
- Botón de búsqueda.
- Botón "Voy a tener suerte".
- Diseño responsive.
- Interfaz inspirada en la página principal de Google.
